FORGE

A forge for your developer workflow.

A local-first developer workbench for small teams and maintainers who want dependable project checks, visible repository health and clearer automation boundaries without adopting another hosted control plane.

View on GitHubProject website

What it does

Init and doctor

Creates a local config, a default-deny policy and a JSONL event log, then checks Node.js, Git and project manifests.

Inspect

Audits open-source repository readiness without running project scripts or making network calls.

Verify

Runs discovered lint, typecheck, test and build scripts in npm, pnpm, Yarn or Bun projects.

Guard

Evaluates a tool name against explicit allow and deny lists. Deny always wins.

Webhooks

Verifies raw webhook payloads with HMAC-SHA256 and a secret read from the environment.

Trace

Lists recent local verification, guard and webhook events as evidence of what ran.

Try it

git clone https://github.com/NetCore-Technologies/FORGE.git
cd FORGE
npm install
npm link
forge init
forge doctor
forge verify .

Early development. The npm package isn’t published yet, so run it from source. The guard evaluates policy decisions only and is not a security boundary.
